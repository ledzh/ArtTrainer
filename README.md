# 🎨 Art Trainer

> Веб-тренажёр для художников: ежедневные упражнения на линию, цвет, вектор и не только.

**Art Trainer** — это браузерный инструмент для практики базовых художественных навыков. Вместо хаотичных скетчей вы выполняете короткие структурированные упражнения с мгновенной обратной связью: точность линии, попадание в цвет, работа с кривыми Безье, температурой оттенка и даже «слепое» рисование по памяти.

Проект создан для художников, которые хотят поддерживать форму между большими работами, и для новичков, которым нужна понятная система тренировки глаза и руки.

---

## ✨ Возможности

- **Линия** — обводка фигур строго по контуру: выход за границы сбрасывает прогресс к чекпоинту.
- **Цвет** — подбор оттенка ползунками тона, насыщенности и яркости с допуском от 25% до 5%.
- **Вектор** — совмещение кривой с эталоном через направляющие узлов (перегиб / сглаженный / симметричный).
- **Температура цвета** — определение тёплых и холодных оттенков, включая нюансы пастельных тонов.
- **Сила нажатия** — аркадный режим: удержание пера управляет высотой полёта, скорость растёт каждые 50 метров.
- **Слепой контур** — запоминание фигуры за 5 секунд и воспроизведение по памяти без видимого холста.
- **Уровневая система** — постепенное усложнение и сужение допусков.
