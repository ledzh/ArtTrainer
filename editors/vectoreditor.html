Готовый код

Узлы:
• ◆ Перегиб — направляющие независимы, можно сделать резкий угол с кривыми.
• ◐ Сглаженный — направляющие смотрят в противоположные стороны, длина разная.
• ● Симметричный — направляющие противоположны и равны по длине.

Мышь:
• Клик по пустому месту — точка (тянуть — сразу с направляющими)
• Клик по направляющей — тянуть
• Клик по точке — выделить / двигать
• Правый клик по точке — удалить
• Средняя кнопка мыши — панорама
• Колесо мыши — зум

Клавиши:
• 1 2 3 — тип выделенного узла
• Delete — удалить точку
• + / − / 0 — зум
